# PhishGuard AI

**AI-Powered Phishing Detection & Analysis System**

## Features

- **URL Phishing Scanner** — 25-feature heuristic analysis (length, entropy, suspicious TLDs/keywords, IP hosts, punycode, `@` disguises, and more), never visits/executes/downloads the URL.
- **Local Machine Learning** — a scikit-learn classifier (Random Forest by default; Gradient Boosting and Logistic Regression selectable) trained and run entirely on-device. No cloud AI, no API key.
- **Explainable AI** — every scan shows a 0-100 risk score, a classification band, and a full list of severity-ranked, human-readable indicators (never just a bare probability).
- **Local Threat Intelligence** — user-editable local lists (suspicious domains, TLDs, keywords, regex phishing patterns, disposable email domains), fully offline, with a modular architecture ready for optional free sources later.
- **Domain Analysis** — safe local domain/subdomain/TLD parsing plus optional DNS lookups (A/AAAA/MX/NS/CNAME) that gracefully show "DNS ANALYSIS UNAVAILABLE" offline instead of crashing.
- **Email Phishing Analyzer** — detects urgency language, credential/financial requests, account-suspension language, and brand impersonation; automatically extracts and re-scans embedded URLs.
- **Email Header Analyzer** — parses SPF/DKIM/DMARC results and flags From/Return-Path/Reply-To domain mismatches and suspicious sending IPs.
- **Local Risk Engine** — combines heuristics, ML, threat intel, and domain analysis into one explainable score with a clear "risk assessment, not a guarantee" disclaimer.
- **Local SQLite Scan History** — search, filter, sort, view, delete, and export every past scan.
- **Report Generation** — professional HTML, JSON, and CSV security analysis reports, no paid software required.
- **Professional SOC-Style GUI** — PySide6 dark theme, sidebar navigation, stat cards, tables, status indicators, and responsive background-threaded analysis (the UI never freezes).
- **Offline Mode** — every core feature (scanning, ML, email/header analysis, risk scoring, history, reports) works with zero internet connection. An explicit `OFFLINE MODE` / `ONLINE` indicator is always visible.
- **Windows-Ready Deployment** — one-click `setup_windows.bat`, `run_windows.bat`, and a `build_windows.bat` that packages a portable `PhishGuardAI.exe` via PyInstaller — no installer, no Docker, no WSL required.

## How Detection Works

1. **URL heuristics** — 25 numeric features extracted via `urllib.parse` (never fetched/executed) are turned into severity-ranked indicators.
2. **Local ML prediction** — a locally trained scikit-learn model scores the same feature vector.
3. **Local threat intelligence** — the URL/domain is checked against fully local, editable lists and regex patterns.
4. **Domain analysis** — safe local parsing, plus optional DNS enrichment.
5. **Risk engine** — combines all four signals into a single weighted 0-100 score and a 5-band classification (SAFE → CRITICAL), always shown with the *why*, never just a number.

Full detail: `docs/detection-engine.md`.

## Machine Learning

- Default algorithm: **RandomForestClassifier** (also supports Gradient Boosting and Logistic Regression).
- Trained locally from `datasets/sample_urls.csv` — a synthetic, safe, clearly-labeled demonstration dataset (see `docs/ml-model.md` for full disclosure of how it was constructed).
- Metrics (accuracy, precision, recall, F1, confusion matrix, ROC-AUC) are always computed from the actual held-out test split — **never fabricated**.
- Model + metadata stored locally at `models/phishing_model.joblib` / `models/phishing_model_meta.json`.
- Retrain any time from the **ML Model** tab or via `python scripts/train_model.py --algorithm random_forest`.

Full detail: `docs/ml-model.md`.

## Offline Mode

PhishGuard AI is offline-first by design. With no internet connection:

- ✓ URL analysis, ML detection, email analysis, header analysis, risk scoring, local database, and reports all continue to work exactly as online.
- The Dashboard shows `MODE: OFFLINE` instead of crashing or blocking.
- DNS lookups (optional) show `DNS ANALYSIS UNAVAILABLE` instead of hanging.
- The connectivity check itself has a bounded timeout and never raises.

## Installation

### Requirements

- Windows 10/11 (also runs on macOS/Linux from source)
- Python 3.12+ ([python.org](https://www.python.org/downloads/), free)
- No credit card, no account, no subscription

### Quick Start (Windows)

```bat
setup_windows.bat
```

This single script checks Python, creates a virtual environment, installs all free dependencies, creates required directories, initializes the local database, generates the sample dataset (if missing), trains the local ML model, and leaves the app ready to run.

### Manual Setup (any OS)

```bash
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
python scripts/init_db.py
python scripts/generate_dataset.py
python scripts/train_model.py --algorithm random_forest
python app/main.py
```

## Windows Usage

```bat
run_windows.bat
```

Launches the GUI directly (activates the virtual environment and runs `app/main.py`).

## Windows EXE Build Instructions

```bat
build_windows.bat
```

Uses PyInstaller (free) to produce a portable executable at `dist\PhishGuardAI\PhishGuardAI.exe`. Copy the whole `dist\PhishGuardAI` folder to run it portably — from any folder or a USB drive — no installer, Docker, WSL, or VM required.

## Security

- Never visits, executes, or downloads content from a submitted URL.
- Never runs user input through a shell.
- Never stores passwords or requires any credential.
- No API secrets in source code — none are required.
- Parameterized SQL only; input length validation everywhere; rotating, secret-redacting logs.

Full detail: `SECURITY.md` and `docs/security.md`.

## Limitations

- The bundled ML dataset is small and synthetic/demonstration-grade — real-world accuracy depends on retraining with a larger, properly sourced dataset.
- Local threat-intelligence lists ship with a small sample set; effectiveness grows as you curate them for your environment.
- DNS/connectivity checks are best-effort and optional; they never gate core detection.
- This tool provides a **risk assessment**, not a definitive verdict — always apply human judgement and organizational security processes.
- Email header spoofing analysis surfaces indicators only; it cannot definitively prove malicious intent.
